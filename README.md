# 🛒 E-Commerce Store SQL Schema

This project contains a **fully-featured MySQL database schema** for an E-Commerce platform. It covers everything from product listings and customer orders to admin users, product reviews, shipping tracking, and more.

---

## 🧩 Database Features

- **Product Catalog** with categories and images
- **Customer Accounts** and wishlists
- **Order Management** including items, status, and payments
- **Shipping Details** with tracking support
- **Product Reviews** and star ratings
- **Discount Coupons** for promotions
- **Admin Users** with roles
- **Inventory Logs** for restocking and sales history

---

## 🛠️ How to Use

### 1. Create the Database

Run the following command in MySQL to create and select the database:

```sql
CREATE DATABASE `E_commerced_Store_Database`;
USE `E_commerced_Store_Database`;
